## Benefício desta Disciplina
A matéria de Laboratório de Programação é o coração da formação de um desenvolvedor. Aqui, os benefícios vão além da escrita de código:
1. **Resolução de probelma complexos:** Você aprenderá a decompor grandes desafios em pequenas tarefas tratáveis.
2. **"Mentalidade mão na massa:"** A disciplina foca na experimentação. O erro aqui não é um fracasso, mas um passo necessário para o aprendizado.
